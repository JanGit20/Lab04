Wprowadzenie do interfejsu .NET CLI

Interfejs wiersza poleceń .NET (CLI) to wieloplatformowy zestaw narzędzi służący do tworzenia, budowania, uruchamiania i publikowania aplikacji opartych na platformie .NET.

Sekwencja utworzenia i uruchomienia aplikacji

Poniższy blok przedstawia kompletną procedurę przygotowania i startu nowego projektu konsolowego:

# 1. Sprawdzenie wersji oraz zainstalowanych SDK
dotnet --version
dotnet --list-sdks

# 2. Utworzenie nowego projektu konsolowego w katalogu App
dotnet new console -o App

# 3. Wejście do folderu projektu
cd App

# 4. Przywrócenie zależności projektu
dotnet restore

# 5. Kompilacja projektu
dotnet build

# 6. Uruchomienie aplikacji
dotnet run

# 7. Czyszczenie plików wyjściowych kompilacji
dotnet clean

Tabela poleceń .NET CLI

Zestawienie najważniejszych poleceń .NET
Polecenie Opis działania
dotnet --version Wyświetla aktualnie używaną wersję zestawu .NET SDK.
dotnet --list-sdks Wypisuje listę wszystkich zainstalowanych wersji .NET SDK w systemie.
dotnet new list Wyświetla listę dostępnych szablonów projektów możliwych do wygenerowania.
dotnet new console Tworzy nowy projekt aplikacji konsolowej.
dotnet restore Przywraca zależności i narzędzia zdefiniowane w pliku projektu.
dotnet build Kompiluje kod źródłowy projektu oraz wszystkie jego zależności do postaci binarnej.
dotnet run Kompiluje (jeśli potrzeba) i natychmiast uruchamia aplikację.
dotnet clean Usuwa pliki wyjściowe i tymczasowe wygenerowane podczas kompilacji.
